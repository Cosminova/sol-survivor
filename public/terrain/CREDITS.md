# Terrain credits (laser altimetry, public domain)

Generated by `node scripts/fetch-3d-assets.mjs` (range-requests only the rows needed, resamples to 256x256 Int16, 0.25 m steps).

- Mars (jezero, gale, arcadia, utopia): MGS Mars Orbiter Laser Altimeter (MOLA) MEGDR, 128 px/deg (463 m/px),
  PDS Geosciences Node, https://pds-geosciences.wustl.edu/missions/mgs/megdr.html
- Moon, Tranquility: LRO Lunar Orbiter Laser Altimeter (LOLA) LDEM_512 (59 m/px),
  https://pds-geosciences.wustl.edu/missions/lro/lola.htm
- Moon, Shackleton: LRO LOLA LDEM_85S_40M polar stereographic (40 m/px); base placed on the highest rim point.

Each `{site}.json` sidecar records the exact source file URL, resolution and relief.
